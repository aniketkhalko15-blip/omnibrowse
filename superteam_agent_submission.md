## 📌 Executive Summary
**OmniBrowse** is a universal autonomous browser execution engine engineered specifically for AI Agents and LLM-driven workflows. Unlike brittle headless scrapers that trigger bot detection, OmniBrowse provides:
1. **Persistent Session Context:** Saves cookies, authenticated states, and localStorage across agent runs.
2. **Stealth Anti-Detection:** Bypasses basic fingerprinting and AutomationControlled flags.
3. **LLM-Optimized DOM Indexing:** Converts messy HTML into token-efficient, numbered interactive elements ready for multi-modal decision-making.

---

## 🛠️ Architecture & Core Components
- `omnibrowse/browser.py`: Core Playwright wrapper with persistent Chromium context and visual DOM indexing.
- `omnibrowse/agent.py`: Autonomous perception-action loop mapping user intent into structured browser actions (`goto`, `click`, `type_text`, `screenshot`).
- `omnibrowse/antigravity_app.py`: Real-time chat & control interface.
